# AI Collaboration Notes

## Form guidance

- Do not use placeholder text as the primary way to communicate form meaning or instructions.
- Use persistent labels for every input, textarea, select, and search field.
- When extra guidance is needed, add helper text adjacent to the control instead of placeholder copy.

## Tool-specific AI work

- When implementing or updating integrations for a specific AI tool or model provider, use that tool's official documentation as the source of truth.
- Keep vendor-specific behavior, naming, and constraints aligned to the corresponding official docs instead of generalizing across providers.
- If multiple AI tools are supported, document provider-specific differences explicitly rather than assuming the same behavior across all of them.
